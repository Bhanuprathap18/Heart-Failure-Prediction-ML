# Dataset

The notebook downloads the dataset at runtime rather than storing a copied dataset in this repository.

Public source/reference:
https://github.com/briggyx/heart_failure_dashboard

Raw CSV:
https://raw.githubusercontent.com/briggyx/heart_failure_dashboard/main/data/heart_failure_clinical_records_original.csv

The referenced source describes a 5,000-patient heart-failure dataset with 13 columns, including `DEATH_EVENT`.

This project is for educational/research purposes and is not a medical diagnostic system.
